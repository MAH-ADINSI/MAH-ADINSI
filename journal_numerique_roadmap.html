Roadmap de développement — Journal Papier vers Journal Numérique Intelligent

1
MVP — Scan local Priorité haute 6–10 semaines
Valider l'idée rapidement, sans backend ni cloud
Technologies
Android (Kotlin) Google ML Kit OCR Room Database CameraX Jetpack Compose
Tâches concrètes
Créer le projet Android (Android Studio, SDK 24+)
Intégrer CameraX pour capturer une photo de page
Connecter Google ML Kit pour l'OCR (image → texte)
Créer une base de données Room (entrée = texte + date + photo)
Écran liste des entrées (triées par date)
Écran lecture d'une entrée (mode lecture seule)
Tester avec 5–10 vraies pages de journal
Débutant : commencer par un tutoriel CameraX officiel (Android Developers), puis ajouter ML Kit. Chaque étape = une branche Git.
2
V1 — Compte & Cloud Priorité moyenne 6–8 semaines
Sécuriser les données, accès multi-appareils
Technologies
Firebase Auth Firestore Firebase Storage Jetpack Security
Tâches concrètes
Créer un projet Firebase, activer Auth (email/Google)
Écran inscription / connexion
Synchronisation des entrées vers Firestore
Upload des photos vers Firebase Storage
Recherche full-text locale dans les textes OCR
Édition du texte OCR (correction manuelle)
Chiffrement de base des données sensibles en local
Débutant : utiliser la console Firebase (interface graphique) pour créer les règles de sécurité Firestore avant d'écrire du code.
3
V2 — IA & Analyse Différenciation 8–12 semaines
Transformer les textes en mémoire intelligente
Technologies
API Claude / OpenAI Cloud Functions Firebase ML Kit NLP MPAndroidChart
Tâches concrètes
Résumé automatique des entrées via LLM (Cloud Function)
Détection d'émotions basique (ML Kit ou API)
Dashboard : courbe d'humeur sur 30 jours
Nuage de mots fréquents par période
Génération de "chapitres de vie" (regroupement par thème)
Notifications intelligentes ("Il y a 1 an, tu écrivais...")
Débutant : commencer par un appel API simple (résumé d'une entrée) avant de construire tout le pipeline IA.
4
Premium — Monétisation Revenu 4–6 semaines
Modèle freemium, abonnement mensuel/annuel
Technologies
Google Play Billing iTextPDF / PDFBox RevenueCat AES-256 Encryption
Tâches concrètes
Intégrer Google Play Billing (abonnement mensuel)
Export PDF : mise en page "livre de vie" (iTextPDF)
Chiffrement avancé AES-256 des données cloud
Paywall : limiter les scans gratuits (ex : 10/mois)
Page paramètres Premium avec gestion abonnement
